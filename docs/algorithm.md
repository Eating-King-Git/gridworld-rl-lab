# 价值迭代与环境语义

## 状态、转移与奖励

模型的状态是网格坐标 `(row, column)`。起点固定在左上角，目标固定在右下角；模型允许从任何非终止位置规划。

每个动作确定地改变一个坐标。越界时原地不动；进入目标的这次转移获得 1，其他转移奖励为 0。规划模型把目标视为吸收状态：从目标出发仍停留在目标，后续奖励为 0。交互环境在回合结束后要求先 `reset()`。

## Bellman 更新

同步价值迭代每一轮只读取上一轮的价值表：

```text
V_next(s) = max_a [r(s,a,s') + gamma * V(s')]
```

当转移到目标时，不再 bootstrap 后续价值。目标本身的价值固定为 0。初始表为全 0，默认在相邻两轮的最大差小于 `1e-12` 时停止，同时设定最大迭代次数。程序拒绝不合理的折扣率、容差和迭代预算，未收敛会显式报错。

Bellman 残差使用最终价值表重新代入更新公式，检查 `max_s |V(s) - T(V)(s)|`，它与最后两轮的变化量是两个指标。

## 不依赖实现的核验

在这个没有障碍、只有终点奖励的确定性网格中，从非终点状态到目标的曼哈顿距离为 `d`。最短路径的奖励在第 d 步获得，因此：

```text
V*(s) = gamma^(d-1)     d > 0
V*(goal) = 0
```

终点前一格不论折扣率多少都能立即获得 1。gamma=0 时更远位置的最优价值为 0，但这不表示从该处不能到达目标，只表示不计未来奖励。默认 5×5 中起点距离为 8，所以 gamma=0.9 时起点价值为 0.4782969。

数学测试以独立的曼哈顿距离公式作为 oracle，比较 2×2、5×5、8×8 和三种折扣率，不直接把实现自己的理论值函数当唯一验证依据。

## terminated 与 truncated

到达目标是任务定义的终止；默认 50 步上限是采样／演示时防止无限运行的截断。观察中没有“剩余步数”，价值迭代也没有把该上限纳入转移模型。该区别遵循 [Gymnasium 对时间限制的说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)。

如果要研究固定期限内必须到达目标的有限时域问题，应把剩余步数纳入状态，或使用随时间变化的价值表。本项目首版没有实现这个扩展。

## 演示策略

`make_demo_video.py` 使用 gamma=0.9 的价值表，对每一步选择 action value 最大的动作；平局时使用 NumPy argmax 的固定顺序。默认网格得到八步路径。GIF 和视频是环境渲染结果，不是人工操作录像，也不是一个经过训练的神经网络。
